# Evidencia de Skill propia y MCP

La skill propia `odontologia-openspec` concentra invariantes del dominio odontológico y se integra al registro del proyecto. Se creó con la guía global `skill-creator` (fuente Anthropic Skills), no la genera OpenSpec; Codex también documenta su `$skill-creator` integrado. Su aplicación en C-21, selección de MCP, consulta y límites están en [investigación](../skills-mcp/investigacion.md) y [aplicación](../skills-mcp/aplicacion.md).

Context7 fue el MCP seleccionado para C-21. Una llamada GitHub MCP anterior se aplicó al change archivado C-20 y no cuenta como uso en C-21. La respuesta Context7 no definió semántica ARIA; se contrastó con W3C. No se afirma revisión humana de terceros ni prueba con lector de pantalla.

Para la exposición, mostrar el SKILL.md, su registro, el change C-21 archivado, los tests/build observados y los informes locales. Explicar con palabras propias las decisiones y limitaciones.
