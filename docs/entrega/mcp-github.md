# Alternativa MCP evaluada: GitHub

GitHub MCP Server es una alternativa oficial para buscar y consultar repositorios, además de administrar Issues, pull requests y Actions. Su amplitud requiere elegir permisos/toolsets adecuados. Se comparó con Context7 en la aplicación C-21; se eligió Context7 para consultar documentación de React y no se conectó ni invocó GitHub MCP como parte de C-21.

Una búsqueda GitHub efectuada antes sobre `GET /reportes/agenda` perteneció al trabajo archivado C-20; no se presenta como evidencia de uso en C-21. Consultar [investigación](../skills-mcp/investigacion.md) y [aplicación](../skills-mcp/aplicacion.md).

Fuentes oficiales, consultadas 2026-11-04: [servidor](https://github.com/github/github-mcp-server), [guía de instalación en Codex](https://github.com/github/github-mcp-server/blob/main/docs/installation-guides/install-codex.md).
